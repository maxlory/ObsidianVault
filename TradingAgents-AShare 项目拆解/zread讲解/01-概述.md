**TradingAgents-AShare** 是一个基于多智能体协作的 A 股深度投研系统，它模拟顶级投研机构的决策闭环——7 位分析师同步作业产出多维度报告，多头与空头研究员展开 Claim 驱动的结构化辩论，交易员形成可执行方案后，激进/稳健/中性三方风控辩论审查风险，最终由风险经理裁决输出结构化交易建议。整个流程由 LangGraph 状态机编排，14 名专业 Agent 在有向图中并行、辩论、裁决，最终收敛为方向、置信度、目标价与止损价四位一体的决策卡片。

## 为什么选择 TradingAgents-AShare？

传统量化系统依赖硬编码规则，对市场结构性变化的适应力有限。TradingAgents-AShare 采用了截然不同的范式——**让 LLM 驱动的专业 Agent 扮演真实投研团队角色**，通过辩论对抗消除单点偏差，通过风控博弈约束激进倾向，通过记忆与反思机制积累跨交易日经验。这种架构的核心优势在于：每个 Agent 的推理过程可追溯、可审计，辩论中的论据锚定在数据工具返回的事实上，而非模型的自由联想。

## 14 名专业 Agent

系统中的 14 名 Agent 被组织为四个功能团队，每个团队内部有明确的协作与对抗关系：

| 团队 | Agent | 核心职责 | LLM 类型 |
| --- | --- | --- | --- |
| **分析师团队** | Market Analyst | 技术指标、K 线形态、趋势判断 | Quick Think |
|  | Social Media Analyst | 舆情热度、社区情绪 | Quick Think |
|  | News Analyst | 新闻事件、全球资讯、内幕交易 | Quick Think |
|  | Fundamentals Analyst | 财报、资产负债表、现金流、利润表 | Quick Think |
|  | Macro Analyst | 板块资金流向、宏观经济 | Quick Think |
|  | Smart Money Analyst | 个股资金流向、龙虎榜、主力动向 | Quick Think |
|  | Volume Price Analyst | 量价关系、VPA 预计算指标 | Quick Think |
| **研究辩论** | Bull Researcher | 多头论证、Claim 提出与反驳 | Quick Think |
|  | Bear Researcher | 空头论证、Claim 提出与反驳 | Quick Think |
|  | Research Manager | 综合裁决、形成投资计划 | **Deep Think** |
| **交易执行** | Trader | 将投资计划转化为可执行方案 | Quick Think |
| **风控博弈** | Aggressive Debator | 激进立场、发掘上行机会 | Quick Think |
|  | Conservative Debator | 稳健立场、强调下行风险 | Quick Think |
|  | Neutral Debator | 中性立场、平衡多空 | Quick Think |
|  | Risk Judge | 三方裁决、决定通过/修订/否决 | **Deep Think** |

只有 Research Manager 和 Risk Judge 使用 Deep Think 模型（如 gpt-4o），其余 12 名 Agent 使用 Quick Think 模型（如 gpt-4o-mini）。这种不对称设计在保证裁决质量的同时控制了 Token 成本。

## 核心能力

| 能力 | 说明 |
| --- | --- |
| **意图驱动交互** | 输入"调研茅台短线"即可自动识别标的、解析投资周期，由 `IntentParser` 将自然语言转为结构化 `UserIntent` |
| **辩论对战可视化** | 前端 Drawer 组件实时渲染多空对抗与风控三方辩论，Token 级 SSE 流式推送 |
| **自选股 & 定时分析** | 数据库持久化自选列表，支持自定义触发时间，连续失败 3 次自动停用 |
| **持仓追踪看板** | 导入持仓数据后自动记录成本与仓位，一键补齐定时分析列表 |
| **结构化研报** | 分析结果按标的/日期存储，决策卡片展示方向、置信度、目标价、止损价 |
| **多模型厂商** | OpenAI / Anthropic / Google Gemini / DeepSeek / Moonshot / 智谱 / 硅基流动，前端自由切换 |
| **REST API** | 标准化 API 接口，支持集成自定义脚本、交易机器人或第三方看板 |

## 技术栈

| 层级 | 技术 | 用途 |
| --- | --- | --- |
| **智能体编排** | LangGraph + StateGraph | 有向图状态机，条件路由，检查点持久化 |
| **LLM 接入** | LangChain + Factory Pattern | 多厂商统一接口，Deep/Quick 双模型配置 |

| **前端框架** | React + TypeScript + Tailwind CSS + Vite | SPA、响应式 UI、辩论可视化 |
| **部署** | Docker + Uvicorn | 一键部署，生产就绪 |
