# Day 1：搭台子 + 把题目和数据跑通

## 第 0 章 · 读懂这道题（30 min）

### "单日涨幅过 7%"是什么

一只股票某天的涨幅 = `今日收盘价 / 昨日收盘价 - 1`。涨幅超过 7% = 当天有明显资金进场的**强势股**。
（A股涨停：主板 ±10%、创业板/科创板 ±20%。所以 7% 是一个"接近涨停或明显异动"的强势门槛。）

老师给的两张图——锐捷网络（+14%）、星网锐捷（+10% 涨停、7天5板）——就是两个"涨幅过 7%"的活样本。

### "套利"在这里的真实含义 ⚠️

老师说的"套利"**不是**学术上的无风险套利（期现、ETF 折溢价那种）。结合图里的强势涨停股，这里指的是 A股短线圈的「**打板 / 涨停接力**」——用"涨幅过 7%"当强势信号，博次日的溢价。**这是有风险的短线博弈，不是无风险套利。** 心里要清楚这一点。

### 解题的三步骨架（整个教程就围绕这三步）

1. **筛选**：从全市场历史数据里，把"单日涨幅>7%"的股票和日期全找出来 → 候选池。（第 3 章）
2. **定规则**：涨幅>7% 之后怎么交易才算"套利"？次日开盘买、收盘卖？（第 4 章）
3. **回测验证**：这个规则在历史上到底赚不赚钱？胜率多少？（第 4、5 章）

### 复权是什么、为什么必须懂（编程本体，别跳过）

<font color="#92d050">**除权除息**：公司分红或送股时，股价会"技术性"下调。例：10 送 10，昨天收盘 20 元，今天理论开在 10 元——但你手里股份翻倍了，**一分没亏**。</font>

如果用不复权价，回测程序会看到"股价一夜腰斩"，误以为暴跌、触发止损，**结果全错**。所以**回测必须用复权价**。

`load_daily` 默认给你**后复权**价（历史价固定、加新数据不改历史，回测标准）。想验证它真的修好了跳空，跑：

```bash

```

**你应该看到**：茅台某个除权日，"不复权"显示下跌、"后复权"是连续的——假跳空被抹平了。

> **一句话记住**：算涨幅、算收益，都要用**复权后**的价格。

## 第 3 章 · 第一个战果：筛出所有"涨幅>7%"（2 h）

### 涨幅怎么算（本体）

`当日涨幅 = 今日收盘 / 昨日收盘 - 1`。在 pandas 里，复权收盘价的 `.pct_change()` 就是每日涨幅。

### 动手 1：先筛单只票

```python
import sys
sys.path.insert(0, "/Users/aa00158/xquant-learning/_my")
from astock_data import load_daily

df = load_daily("sh600519")                 # 后复权
df["pct"] = df["close"].pct_change()        # 每日涨幅
big = df[df["pct"] > 0.07]                   # 涨幅>7%的日子
print(f"茅台历史上涨幅>7%的天数：{len(big)}")
print(big[["close", "pct"]].tail())
```

**你应该看到**：茅台历史上涨幅>7%的具体日期和当天收盘价。

> 小提醒：算涨幅一定要用复权价的 `pct_change()`。如果用不复权价，除权日会冒出"假涨幅/假跌幅"。

# Day 2：把"套利"变成能验证的策略

## 第 4 章 · 你的第一次回测：这套利赚钱吗（2 h）

### 什么是回测（本体）

**回测 = 拿历史数据模拟"如果当时按这个规则交易，结果会怎样"。** 它不能预测未来，但能告诉你一个想法**在过去有没有效**——这是量化和"拍脑袋炒股"的根本区别。

### 我们要验证的规则

最朴素的"套利"：**今天涨幅>7% → 次日开盘买入 → 次日收盘卖出**。收益 = `次日收盘/次日开盘 - 1`。
（`screen_gain7.py` 已经帮每个事件算好了，就是那列 `retA`。）

### 动手：看结果

`screen_gain7.py` 跑完就打印了统计。真实全市场结果：

```
[口径A 开盘买/收盘卖] 次日收益：
  平均 +0.03% | 中位数 +0.00% | 胜率(为正) 44.9% | 标准差 4.77%
  最好 +94.29% | 最差 -51.82%
```

### 震撼结论 + 解读

**"今天涨>7%、明天开盘就买"这个套利——平均收益 +0.03%（约等于 0），胜率只有 44.9%（还不如抛硬币）。**

为什么？因为涨幅>7% 的票**次日往往高开**，你在高开的位置追进去，然后回落。你以为抓住了强势股，其实是在给前一天的买家抬轿。

> **这就是这道题最重要的一课**：一个听起来合理的"套利"，用数据一测，没有优势。**大部分朴素想法都是这样——量化的价值就是快速证伪它们，而不是凭感觉相信。**

那有没有办法改进？进第 5 章。

## 第 5 章 · 从粗筛到精筛：alpha 到底在哪（2.5 h）

### 核心思想

无脑筛"涨幅>7%"没优势 → 那就**加条件**，看什么样的>7%事件次日更可能赚。这个"找有效条件"的过程，就是量化选股的精髓。

### 动手

```bash
python _my/analyze_filters.py
```

它把 46 万个事件按不同维度分组，对比次日胜率。真实结果：

**① 按"次日开盘跳空"分组 —— 低吸 vs 追高**

```
次日低开 <0%    n=176,019 | 平均 +0.51% | 胜率 50.4%
平开 0~2%      n=145,166 | 平均 +0.21% | 胜率 48.2%
高开 2~5%      n= 69,813 | 平均 -0.10% | 胜率 46.8%
高开 >5%       n= 72,538 | 平均 -1.34% | 胜率 22.8%   ← 追高是灾难
```

👉 **最强发现：买入点比选股更重要。** 次日低开时买，胜率 50.4%；次日大幅高开还去追，胜率只有 **22.8%**——差 28 个百分点！这正是你资料里那些"**首板低开策略**"的智慧（`聚宽2025年精选/1首板低开策略.txt`、`78首板低开策略-终极版.txt`）：专挑低开的买，因为便宜、有安全垫。

**② 按"今日涨幅"分组 —— 涨停买不进的真相**

```
涨 7~9.8% (主板未封死)  n=181,582 | 胜率 48.9% | 平均 +0.30%
涨 ~10%   (主板涨停)    n=244,499 | 胜率 41.9% | 平均 -0.16%
```

👉 涨停封死的票次日反而更差——**而且封死了你根本买不进**。破除"追涨停最强"的迷信。

**③ 组合精筛**（次日低开 + 没涨停 + 小市值）：胜率 50.8%、平均 +0.45%，比基线（44.9%）提升约 6 个百分点。

### 但是——诚实的一课 ⚠️

即使精筛到 50.8% 胜率、平均 +0.45%，**扣掉成本后还是不赚钱**：
- 手续费万 3 双边 ≈ 0.06%，卖出印花税 0.05%，再加滑点（你未必买在开盘价）……
- 平均 +0.45% 的毛收益，扣完基本归零甚至为负。

**结论：这道题的朴素解法，没有稳定的 alpha。** 简单到"一个涨幅阈值 + 几个过滤"就能发现的规律，早被市场消化了。真正的打板高手赚的钱，藏在你**本地日线数据看不到的地方**：分时盘口、封单强度、龙虎榜资金、题材情绪、连板梯队——这些要 Level-2 / 分钟 / 竞价数据。

## 第 6 章 · 认清真相 + 交作业（1 h）

### 为什么聚宽那些"年化 304%"你别信

你资料里 `7追首板涨停 过去两年年化304%.txt` 这种标题——**打板策略是回测最容易骗人的重灾区**：
- **一字板买不进**：回测假设你按开盘价成交，但真实的强势首板经常一字涨停，你挂单根本排不上。
- **滑点**：真实成交价比回测差。
- **幸存者偏差**：作者调参数直到某段历史好看，换个时间段就崩。

所以：**学它们的"方法和代码结构"，不信它们的"收益数字"。** 你今天用 46 万个事件跑出的诚实结论，比那些标题可信得多。

| 涨停价、封单 | 判断能不能买进 | 聚宽平台 |
| 龙虎榜、题材 | 资金和情绪 | 聚宽 / 东财 |

最省事的进阶路径：**直接上聚宽平台**（你那 100 个策略本就是聚宽的，平台自带全套数据）。

### 📋 交作业：把结果组织成给老师的答案

你现在能给出一份**有真实数据、还诚实指出局限**的答案（模板）：

1. **软件识别**：两张图是**看盘（实时行情）软件**（证据：连续竞价、买卖五档、涨停封单分析），不是回测软件。
2. **解题方法**：三步——全市场筛选涨幅>7% → 定义"次日开盘买/收盘卖"规则 → 回测验证。
3. **实证结果**（你亲手跑的）：
   - 46 万个"涨幅>7%"事件，无脑次日买入：平均 +0.03%、胜率 44.9%，**没有优势**。

   - 组合精筛能到 50.8%，但**扣成本后不赚钱**。
4. **结论**：涨幅>7% 是有效的"强势筛选器"，但朴素套利无稳定 alpha；真正的机会需要日线看不到的盘口/情绪数据。
