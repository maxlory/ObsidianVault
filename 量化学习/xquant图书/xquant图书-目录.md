## 全书最该记住的四件事

**① spec 的第一条要求永远是「先读源码」**（[[00a-准备工作]]）

74 份配套 spec 里，「要求」段第 1~2 条无例外都是「阅读以下 oxq 模块的源码，了解各接口的
输入、输出和参数含义」。因为 **AI 会编造不存在的 API 和参数名**，强制它先读真实源码，调的就是真接口。

**② 固定窗口，禁用 today**（[[00a-准备工作]]）

spec 里明写「不要使用 `today`、`now()` 或默认截止到最新数据的下载方式」。
用 today 的话今天跑和明天跑结果不同，既不可复现，也没法和书里的参考数字对账。

**③ 收盘价零成本回测是最乐观假设**（[[07-执行交易]]）

五种成交价模式跑同一个策略，实测：收盘价（理想）83.22% → 次日开盘价 80.00%，
**光换一个成交价假设就少 3.22 个百分点**。最好与最差之间差 4.45%。

**④ 五个陷阱：指标好看 ≠ 结果靠谱**（[[05-判断策略好不好]]）

拿到漂亮回测先用这五个视角扫一遍——基准陷阱（没和「什么都不做」比）、
整体陷阱（多年累计掩盖某年大亏）、胜率陷阱（胜率 90% 不等于赚钱）、
回撤陷阱（只看深度不看恢复时间）、山峰陷阱（参数稍偏就掉一大截，那是巧合不是规律）。

## ⚠️ 读这本书时要知道的三件事

**1. 书里的代码在当前 oxq 版本下有 1 处会失败。**
配套 notebook 的 55 条 `from oxq... import` 里，`SignalToPositionOptimizer`（[[02-先选买什么]] 用到）
在 oxq 0.1.0 全库不存在。照书抄代码前，拿不准的 API 先查 `API参考.md`。

**2. 书里教的 `EqualWeight` + 信号组合，信号是装饰。**
`EqualWeightOptimizer` 源码只有 `weight = 1.0/len(signals)`，**从不读信号真假值**。
实测把 `Crossover(3/7)` 换成恒真 `Threshold`，结果 bit-for-bit 相同。
想让信号真正生效要用 `TopNRanking`。详见实战坑位清单第 12 条。

**3. 本书只用了 oxq 的 29%。**
教程没教但源码里有的：`RSI`、`MACD` 全套、布林带、`ATR`、`Crossover` 信号、
`PE`/`PB`/换手率等基本面因子、`FilterUniverse`（时点股票池，解决幸存者偏差）、
`AkShareDownloader`（A 股专用下载器）。清单见「教程未覆盖能力审计」。
