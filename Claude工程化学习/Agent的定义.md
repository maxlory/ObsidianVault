	Role：预设Agent解决问题的身份和角度——由于注意力机制和神经网络设计，大模型对输入的第一句的话的注意力很高，更好地激发其对想要知识的应用
Goal：Agent的决策偏好。目标的设定可能会影响Agent采取什么方式来解决问题
Background：Agent的行为&边界。补充相关知识：人设、知识、方法和行为边界

==Role：==
【设计原则】
-角色要具体，避免泛泛而谈
-角色名称应该反映 Agent 的专业领域
-好的角色名称能让 LLM 更好地理解 Agent 的定位

==Goal：==
【设计原则】
-目标要可量化、可評估
-目标应该与业务 KPI 对齐
-清晰的目标有助于 Agent 做出正确的决策


好的 ==backstory== 应该包含四个部分：
1. Identity & Context（身份锚点）：让 Agent 知道"我是谁“
2. Knowledge（知识储备）：让 Agent 知道”我懂什么"
3. Methodology & Mindset（方法论）：让 Agent 知道“我怎么思考"
4. Boundaries（行为边界）：让 Agent 知道”我不做什么"

【设计技巧】
- 使用具体的场景和例子
- 包含专业术语和理论框架
- 明确工作流程和思维模式
- 设置清晰的边界，避免 Agent 越界
