## LangGraph的三个重点
-**State**：State 是 LangGraph 中保存运行信息的共享数据结构，每个节点都会读写它；通过 reducers，新的修改可以和旧数据合并，而不是简单覆盖。
-**Nodes**：可以被视为函数/工具，处理数据并且返回结果
-**Edges**：Edges 是 LangGraph 中连接 nodes 的路线规则，用来决定当前 node 执行完之后，下一个运行哪个 node。（编排路径）

**导入工具**
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

**定义State：规定这个 graph 运行时要保存什么数据。**
class State(TypedDict):
    messages: list[str]
#规定这个 LangGraph 工作流的共享数据结构，让每个节点知道自己可以读写什么数据。（所有 **node** 都会围绕这个 `State` 工作）

**定义 Node：定义处理步骤（工具）
def greet(state: State) -> State:
    return {"messages": state["messages"] + ["hello from the graph"]}
#定义了一个node，输入变量是state，输出变量也是state
#state也是一个包含消息列表的字典

**搭建 Graph 结构：创建 graph，并规定执行流程。**
builder = StateGraph(State)
builder.add_node("greet", greet)
builder.add_edge(START, "greet")
builder.add_edge("greet", END)
#StateGraph(State) 创建的是一个“工作流/流程图框架”，Agent 可以用它来实现。
#StateGraph 不是天然等于 Agent。用 State 管理数据，用 Node 执行步骤，用 Edge 控制流程

 **编译并运行 Graph：把 graph 变成可以运行的对象，然后传入初始 State 执行。**
graph = builder.compile()
#complie()把前面搭好的 graph 结构，真正“编译/组装”成一个可以运行的对象。


定义 State → 定义 node → 搭建 graph （使用edge规划路径）→ 运行 graph → 得到结果
State：graph 运行时共享的数据，用来保存 messages 等信息（只是规定的消息储存器，后续的对话内容都放进这里面）
node 是 LangGraph 流程里的一个步骤（工具）；tool 是这个步骤里面可以调用的外部能力。

术语总结：
用做一个Agent来做类比
StateGraph：设计 Agent 工作流的工作台
State：Agent 的工作记忆，保存用户问题、模型回复、工具结果（数据库）
Node：组成graph的节点（具体步骤），可以调用模型、调用工具、总结结果（工具的配置在这里实现）
Edge：路径，导向下一步的方向
Graph：最终可以运行的 Agent 流程

- **StateGraph**: the builder object. You add nodes and edges to it.  
    StateGraph：这是构建对象。你可以向它添加节点和边。
- **Node**: a function that takes state and returns a partial update.  
    节点：一个接受状态作为输入，并返回部分更新结果的函数。
- **Edge**: a transition from one node to another. Fixed or conditional.  
    边缘：从一个节点过渡到另一个节点。可以是固定的，也可以是条件性的。
- **Compile**: turn the builder into an executable graph.  
    编译：将构建器转换为可执行的图式。
- **Invoke**: run the graph to completion and return the final state.  
    执行操作：运行图表直至结束，并返回最终状态。
- **Stream**: run the graph and yield intermediate state as it progresses.  
    流：在图形运行过程中持续显示中间状态。
- **Checkpointer**: something that saves state between invocations (Chapter 5).  
    检查器：用于在调用之间保存状态的对象（第 5 章）。
- **Thread**: a conversation identifier. Used with checkpointers to resume.  
    主题：对话标识符。与检查指针一起使用，用于恢复对话。
- **Reducer**: a function that merges state updates. Defaults to "replace"; "add" is common for lists.  
    reducer：一种用于合并状态更新的函数。默认值为“replace”；对于列表来说，“add”是常见的操作方式。
