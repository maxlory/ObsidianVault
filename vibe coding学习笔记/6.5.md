from typing import TypedDict
#TypedDict有固定字段要求的表格模板，方便在节点之间传递状态的时候，保持格式的统一性

**TypedDict、Pydantic BaseModel、dataclass 都可以用来定义 State 的“结构模板”。**
告诉 LangGraph：这个 `State` 里面应该有哪些字段，每个字段大概是什么类型。
**1. TypedDict：最像普通字典，最轻量**
**2. Pydantic BaseModel：最严格，会做运行时校验**
**3. dataclass：更像普通 Python 对象**
|**方式**|**像什么**|**访问方式**|**是否运行时校验**|**适合场景**|
|---|---|---|---|---|
|TypedDict|带说明的字典|state["count"]|弱|LangGraph 入门、简单状态|
|BaseModel|严格的数据模型|state.count 或转 dict|强|**复杂数据、需要校验**|
|dataclass|普通数据对象|state.count|弱|Python 内部数据结构|
