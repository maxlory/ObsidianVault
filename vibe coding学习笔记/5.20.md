**命令行命令**
mkdir 创建文件夹
例子：mkdir -p ~/.claude/skills
备注：经常和 -p 一起使用 （-p 表示上层文件夹一起处理。如果上层文件夹存在也不报错）

ls 查看当前文件目录
例子：ls ~/.claude

cd 进入某个文件夹
例子：cd ~/.claude/skills
cd .. 返回上一级
cd ~ 返回主目录

cp 复制文件/文件夹
例子：cp a.txt b.txt     cp -r code-review ~/.claude/skills   
备注：经常和 -r 一起使用（-r 表示复制整个文件夹）

mv 移动/重命名
例子：mv test.txt ~/Desktop/    mv old.txt new.txt

rm 删除文件/文件夹
例子：rm test.txt    rm -r old-project

**Skills学习**
定义：在复杂工作流中可复用、自动触发的技能包
特点：可复用-专业化、渐进加载（渐进式披露）-节省token

什么是渐进式披露：skill不是一次性将所有内容塞入上下文，而是按需加载
怎么按需加载：
	三层加载：
		1. 只看描述（description）
		2. 再加载SKILL.md
		3. 按需加载支持文本（脚本、模板、参考资料）


Hooks学习
定义：在 Claude Code 特定事件发生时自动执行的 shell 命令，用来做格式化、校验、通知、审计等自动化工作。
常见用途
- 写文件前自动格式化
- 提交前运行测试
- 扫描安全问题
- 记录 bash 命令
- 校验用户提示词
- 发送团队通知
