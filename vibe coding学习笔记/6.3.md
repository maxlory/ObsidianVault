控制 agent 行为，同样是分层的，**可靠性递增、灵活性递减**：

|层|对应什么|能给你|给不了|
|---|---|---|---|
|**1. Prompt 层**|AGENTS.md / MEMORY.md / skill description|最强的方向盘，覆盖绝大多数情况|**100% 保证**——一旦和模型判断冲突就可能输|
|**2. Skill 设计层**|让 skill 真提供模型给不了的价值 + 写法不自相矛盾|让模型**"想"**走 skill（指令与判断对齐，冲突消失）|仍非强制|
|**3. Harness / 平台层**|代码强制：命中意图就**自动**注入/执行 skill，不靠模型自觉|**唯一的"硬保证"**（你的 ERP 权限控制）|需要平台支持|
prompt层和skill层终究是浅薄的，Harness层才是重点
想要真正实现Harness，就不能只在Agent.md和skill这两层转悠，必须深入进Agent的底层框架，即使用LangGraph构建Agent
