## §3 各工作线详细框架

### 3.1 财务智能分析 Agent（AgentDaniel）技能体系构建与评测 【核心】

**背景**：公司开发面向财务分析的 AI Agent（基于大模型 + 技能 skill 架构，跑在公司内部 agent 平台 octok 上）。实习初期接手后发现核心问题——agent "计算准但自由发挥"（同一指标 ROE 给出 5 个不同答案），技能系统未被有效触发（多轮测试触发率为 0），需要从能力体系、触发机制、评测体系三方面重构。

**主要工作**：

1. **财务技能体系从 0 到 1 开发（自建 13+ 个技能，贯穿财务全链路）**
   - 数据导入：`financial-data-ingest` — 总账 + 7 个子账协同导入，标准化 JSON schema、FSLI 字典精确 join、汇率快照，脚本 530 行一次跑通
   - 数据分类：`transaction-classifier` — 交易分类器 v2，训练集 12/12、留出集 9/9（补跑后 10/10）全过
   - 数据路由：`financial-file-router` — 文件自动识别路由（PDF/GBK/扩展名造假等），10 道留出集泛化 9/10（反过拟合迭代）
   - 跨文件对账：`cross-file-reconciliation` / `multi-source-detector` / `shortcut-detector` — 仿 Anthropic 架构拆分为多源检测 + 快捷项检测 + 编排 wrapper，11 项钩稽、多源重现、IC 抵销等 4 项测试全过
   - 指标口径强制：`financial-metrics-methodology-enforcer` — 解决"同一指标多个答案"问题，3 轮测试（3 次会话 ROE 一致性、12 指标批量、5 题留出集）全 PASS
   - 报表生成：`us-gaap-financial-statements` — US-GAAP 出表器（科目映射 taxonomy + openpyxl 渲染脚本，支持多期对比 + 派生项公式 + 跨期 checks + RE roll-forward）
   - 分析报告：`financial-analysis-report`（27 指标口径库 + 9 板块报告模板）、`financial-diagnosis`（数据驱动六维打分 + 行业基准三级置信标签 + 指标证据表）
   - 决策辅助：`decision-analyzer`（训练 12/12、留出 10/10，含超额响应亮点）
   - **反向案例**：`financial-qa` 实测触发率 0/12，判断"模型自给自足优于技能"后主动收手不构建——体现工程判断力
2. **Agent 提示词与路由工程（配置体系 v4.1→v4.9 迭代）**
   - 重写 AGENTS.md / SOUL.md / PANEL.md 三层配置：意图路由表（18 条路由规则）、SOUL 重定位为"身份 + 工作哲学 + 文档导航"
   - **根因诊断**：通过 LangSmith trace 分析定位"不调用技能"根因——系统提示词广告 27 个技能但无一真正"拥有"编表任务 + 技能 description 含"坚决不要触发"自逃逸条款 + 模型"自己能干"先验
   - 技能描述优化：重写 10 个技能 description（平均砍 60%），清除自我否定条款，建立"负向边界只用于兄弟技能分流"写作规范
   - **Token 优化**：36 个技能 description 每轮固定烧 ~32K token → 采用 Tool Search（延迟加载）机制，实测**省 85% token 且技能选择准确率从 49% 提升至 74%**
3. **评测体系搭建与自动化**
   - 设计多轮测试题：首轮 11 题 → Phase2 15 题 → Phase3 8 题（国际准则）→ 5 道脏/多源数据对照题，覆盖指标计算、报表生成、脏数据处理、编表派生等场景
   - **自建自动化测试流程**（Chrome MCP）：在 dev 平台批量提交测试题（15 题/30 分钟），解决"文件上传缺失导致测试无效"问题（S3 URL 嵌入、idle 状态判定），全流程沉淀为工作流文档
   - 黑盒测试：不暗示使用技能，3 个核心技能均被 agent 自动触发且答案精确命中基准答案
   - 装/不装技能对照测试：量化技能核心价值在"过程质量"（自检页、差异分级、27 指标溯源）
   - 与公司 agent 对比测试：输出 20 条改进建议报告
   - 构建 5 个中文准则测试 case（覆盖基线/自定义维度/编表派生/行业特殊科目 4 档能力）
4. **交付与国际化**
   - 24 个技能 + 7 个根配置打包交付（daniel-staged），全部中译英、CAS（中国准则）→ US-GAAP 适配
   - 制作展示材料：能力对比表 3 张、展示 HTML、技能详解文档、向领导汇报的 6 节 HTML 报告（摘要→新旧对比→装/不装实测→缺口地图→下阶段→方向浅见）
   - 数据脱敏：清除 24 个技能中公司实名/真实报表数据 89 处

**技术栈**：Claude/大模型 Agent、Python（openpyxl、difflib、yaml）、JSON Schema、Chrome MCP 自动化、LangSmith、OpenClaw/octok 平台、提示词工程

**可量化成果（简历素材）**：
- 自建 13+ 财务技能，全部通过训练/留出集验收（留出集通过率 90~100%）
- 黑盒测试 3/3 自动触发、答案精确命中基准
- 技能触发机制优化：token 消耗 -85%、技能选择准确率 +25pp（49%→74%）
- 自动化测试：15 题/30 分钟（原人工数小时）
- 3 轮摸底测试 49+15+8 题定位能力短板；与公司 agent 对比输出 20 条改进建议
- 交付物：24 技能国际版打包、6 节汇报报告、3 张能力对比表
